# Личный сайт Grigorenko

## Как запустить
1. Распакуй ZIP.
2. Открой `index.html` в браузере.

Структура:
- `index.html` — разметка сайта
- `style.css` — дизайн и адаптивность
- `script.js` — анимации
- `assets/avatar.jpg` — фотография профиля

Все основные тексты и ссылки можно менять прямо в `index.html`.
